      What stays on this computer

      The index is .kttl/geo.sqlite inside your selected folder. Choosing a folder only reads its existing index; making, updating or re-indexing starts only when you press its button. Folder choices and results live in this session and are not logged.

      Use my current location makes one browser geolocation request when you choose it. The browser or operating system may use a network location provider. Geo does not track your movement or store the reading: it fills the search centre, which goes only to this local server when you choose Find photographs.

      JPEG, PNG and WebP previews are read directly from indexed originals, up to 40 MiB each; Geo makes no thumbnails. Other formats can be opened in your file browser. Show in file browser is limited to files held by the selected folder’s index.

      Maps use a bundled local copy of Leaflet and an optional raster MBTiles file you choose. Tile images, markers and previews come only from this server. Packs are opened read-only, never downloaded or changed; their selection lasts for this server session. Outside a pack’s coverage, the map keeps the photo markers and explains the missing background.

      The folder picker uses your computer’s native window. A browser cannot give Geo the full path of a dropped folder, so dropping works only for a uniquely named folder already opened during this server session. Type its full path if necessary.

      Search uses the last completed index. Use Update after editing or moving files. A failed scan keeps the previous index; unsupported, missing-GPS and failed files remain visible in coverage.
