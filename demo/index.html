What's real and what's replayed

  • The page inside the frame is the exact page from the app.
  • Tools built from plain browser code run for real.
  • Tools that rely on a local worker or model can't run in a static website, so each prepared sample was run on a Mac, the worker's replies were recorded, and the demo replays them here. Where a step took a second or more, the demo shows the real timing.
  • Anything not recorded has no reply, and the demo tells you.
  • A demo needs JavaScript. The rest of this site works without it.
