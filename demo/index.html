What is real and what is not

  • The page is the one in the app, unchanged.
  • A tool that is ordinary code in the page runs for real in your browser.
  • The other tools do their work in a program on your own computer, some of them with a model. A website cannot run that. So I ran each prepared example on my Mac and recorded what the tool answered, and the demo replays it. Where a step took a second or more, the demo says how long it really took.
  • Anything that was not recorded has no answer, and the demo says so.
  • A demo needs JavaScript. The rest of this site can be read without it.
