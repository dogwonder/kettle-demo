Kettle

Small tools with results you can check

Kettle builds small tools for the everyday jobs people often hand to AI chatbots. Each one does a single job and puts its draft beside the original so you can check and fix it before you keep it. Where a tool uses a model, Kettle pins the exact file and tests it against real examples before building the app around it.

Who it's for

Charities and small organisations that can't paste their paperwork into a chatbot. They need to trust the numbers and know where their files went.

The funding watch

Small charities usually hear about funding by chance: a search, a newsletter, word of mouth. Every Monday morning, the funding watch checks a charity's chosen funders and emails what changed. Instead of asking a chat model to summarise pages, it pairs plain code with Cloudflare's Clairic and Clef models, which extract single facts and fixed labels rather than writing prose. Every date and amount has to appear on the funder's own page; if a page doesn't say, the email says "Not stated on the page".

It's been running since October 2026 for a small Hackney charity. See how the funding watch works.

Four rules every Kettle tool follows

  1. One job, checked by a person. You see the source beside the result and fix mistakes before saving. No tool sends, books or decides anything for you.
  2. Private files stay on your device. Kettle only uses the cloud for public pages, like funders' websites.
  3. The smallest thing that works. Plain code first, then a small local model, and a large model only when nothing smaller can handle it. Every tool page names its models, or says it uses none.
  4. Show the working. Kettle publishes what was tested, what it was checked against, and where it broke.

Where the tools run

In the cloud
Public pages, read once and shared with everyone who needs them. The funding watch is live.
On a Mac
Your own files: bank statements, meeting recordings, folders of photos. Six tools in development, with three you can try in your browser. Once set up, none of them talk to the network.
On an iPhone
Whatever's in front of you: a food label, a letter, a screenshot. Three tools in development. They work on older iPhones without Apple Intelligence, and the app has no networking code at all.

How Kettle builds them

The tools share the same pattern underneath, which keeps them quick to build and possible to test. Where a tool uses a model, the model proposes an answer and code checks what comes back. Every model is pinned to its exact file, and every new tool starts with a test on real files; ideas that lose get dropped. Read how it works.

Research

Building Kettle means testing hunches and publishing the results whether they hold up or fall flat. In the first study, giving Claude Code a guide to Tables made it do more model work on seven small tables than reading the picture itself. In another, reading short requests about a picture, hand-written rules got 59 of 60 right against 47 or 48 for three small models.
