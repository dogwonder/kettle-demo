Playbooks

Routes across more than one tool

Each tool does one job, so bigger tasks take two or three in a row. A playbook logs a route that's actually been run end to end: which tool goes first, what to check, and which file to save and open in the next one. Kettle only publishes a playbook after walking through it on real files.

Pouring by hand

Passing a result from one tool to the next is a pour, and you do it by hand: save the checked file, then open that file in the next tool. Nothing passes between tools automatically, so the next step always starts from the exact version you reviewed. If you fix something later, the next tool only sees it once you save and reopen the file.

Kettle briefly had an automatic pour from Tables into Regulars. It worked, but poured statements vanished when the app closed, and a year needs twelve statements stored somewhere anyway. Saved files already solved that, so it came back out the same day.
