Playbooks · A year of statements

A year of statements into one list of repeat payees

Two tools in a row. Tables turns each monthly statement into a checked CSV, and Regulars reads all twelve CSVs to list every payee you pay repeatedly. Nothing passes between them automatically — you pour by hand, saving each file and opening it in the next tool.

What goes in and comes out

Start with
Twelve monthly bank statements downloaded as text PDFs (not scans).
End with
One CSV listing every payee you paid 3 or more times across 3 or more months, ranked by yearly total, plus every new payee from the latest statement.
Models used
None. Both tools run plain code for this, so the same statements always produce the same list.

The route

  1. Tables: each PDF into a checked CSV. Open one statement PDF. Rows sit beside images of the pages, with any broken running balance flagged. Check every cell, fix anything off, tick the box and save the CSV. Repeat for all twelve months and keep them in one folder.
  2. Regulars: all twelve months in one list. Open the whole folder of CSVs together. If a balance doesn't add up or two files overlap in dates, Regulars flags it — jump back to Tables for that month, fix it, save over the CSV and reload. Rename or merge payees the bank formatted in two different ways.
  3. Save the list. Regulars keeps nothing once you close the window, so export the summary CSV (and the underlying payments if you want them).

Next month

Run the new statement through Tables and drop its CSV into the same folder, then open the whole folder in Regulars again. "New in the latest statement" lists every payee you hadn't paid before, largest first. Regulars doesn't persist renames or merges, so you'll redo those if you need them.

What to check

  • In Tables, check every cell. Matching running balances confirm the amounts, not the dates or descriptions.
  • In Regulars, nothing new — the summary is only as clean as the CSVs you saved from Tables.

How it went for me

I ran twelve of my own statements from one bank through this route. Every running balance added up and the list needed zero manual merges. One statement took about 20 seconds from download to saved CSV, with a couple of cells to tweak. Regulars still only knows that one bank's column layout; adding a second bank is next once I test against real files from another account.
