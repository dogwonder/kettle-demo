Playbooks · A year of statements

From a year of statements to what I pay for again and again.

Two tools, one after the other. Tables turns each month’s statement into a CSV I have checked, and Regulars reads the year of CSVs and lists every payee I pay repeatedly. Nothing passes between them on its own: I pour by hand, saving each file and opening it in the next tool.

What I start with and end with

Start with
Twelve monthly statements downloaded from my bank as PDFs. Text PDFs, not scans.
End with
One list of every payee I pay 3 or more times in 3 or more months, sorted by what they cost in a year, saved as a CSV. And the names I paid for the first time in the latest statement.
Models used
None. Both tools use ordinary code for this, so the same statements always give the same list.

The route

  1. Tables: each statement to a checked CSV. Choose one statement PDF. The rows appear beside images of the pages, and a row whose printed balance does not add up is marked. Check every cell, correct what is wrong, tick and save the CSV. Do this for each month, and keep the twelve CSVs in one folder.
  2. Regulars: the year in one list. Choose all twelve CSVs together. If a balance does not add up somewhere, or two files cover the same dates, Regulars says so: go back to Tables for that month, fix it, save it again and choose the files again. Rename or merge lines the bank names differently.
  3. Save the list. Regulars keeps nothing when it closes, so save the list as a CSV, and the payments behind it if you want them.

Next month

Take the new statement through Tables and save its CSV into the same folder. Choose the whole folder in Regulars again. “New in the latest statement” shows every name paid for the first time, largest first. Renames and merges are not kept, so make them again.

What to check, and where

  • In Tables, every cell. When every balance adds up, the amounts are right, but not necessarily the dates or descriptions.
  • In Regulars, nothing new. It is only as right as the CSVs checked in Tables.

How it went for me

I took twelve of my own statements, from one bank, along this route. Every running balance added up and the list needed no manual merges. One statement took about 20 seconds from download to saved CSV, and a couple of its cells needed correcting. That is one person’s year from one bank, and Regulars knows only that bank’s column layout so far.
