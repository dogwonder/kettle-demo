Tools · Share Copy

Take the personal details out before you paste

Before pasting a letter or email into a chat model, Share Copy drafts a stripped-down copy with the details you pick removed. It flags names, addresses, contact details, reference numbers and passwords, and you check every suggestion — and the rest of the text — before using it.

How it works

  1. Paste or open the source. Plain text, or a PNG/JPEG photo of a printed letter. For an image, local OCR reads the text first so you can fix OCR mistakes beside the photo.
  2. Review suggestions. A small local model and a set of rules highlight details to strip. Keep or drop each one, and highlight anything else they missed to remove it everywhere it appears.
  3. Read the whole copy. Tick the review box once you've checked the full output, then copy it or save a text file. Your original isn't touched.

What you get is a copy you've checked, not a guarantee that nothing slipped through. Both the model and the rules miss things, so read the unmarked lines too.

Models used

Ettin 68M PII
Flags names, addresses, contact details and identifiers. ~137 MB, MIT licence, revision 500262a2aaf913825ef750ef255c3fe437cd8e64. Caps at 12,000 characters; longer text gets refused rather than silently truncated, though you can still run the rules alone.
Tesseract English (tessdata_fast 4.1.0)
Reads printed English text from images via Tesseract 5.5.2 (~4 MB).
Rules, no model
Catches email addresses, UK phone numbers, labelled references, common API key formats, private keys, card numbers, and values after labels like "Password:" or "API key:". An unlabelled password sitting in a sentence won't be caught.

Both models run on CPU and stay offline after setup. On macOS, the PII model runs in a separate process with network access blocked. Dates, times and job titles aren't flagged.

What's been tested

The main test is an invented housing-repairs letter with every detail to remove listed before running the tool. Between them, the model and rules made eleven suggestions: ten caught real personal details, one only caught half of a repeated flat number, and a description that identified the home was missed completely. Adding those two by hand gave the exact expected output — without reading through, it would have leaked identifying details.

I tried two other small models on the same letter before picking Ettin; none caught everything on its own. I've used Share Copy in my own work since 24 September 2026.

Status and what's next

Not available to download yet. Share Copy runs in the development Kettle app on macOS.

One invented letter isn't a real benchmark, so the open question is what kinds of everyday emails and letters trip Ettin up most often in everyday use.
